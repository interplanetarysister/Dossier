# Disclosures and validation

## Provenance

Dossier's workflow and instructions were newly authored for the UGREEN Hackathon 2026 on 2026-11-11 under the project owner's direction. This is an independent project, not an official or certified UGREEN product.

Authoring and static checking use the official uliya-skill-kit 0.7.3-en, catalog 2.0.0 dated 2026-09-01, available at https://ai.ugreen.com/pages/hackathon-starter-kit. The toolkit is not bundled or relicensed. Its use is subject to UGREEN's applicable agreements. No third-party code libraries, model weights, datasets, fonts or images are included.

Codex/OpenAI was used for requirements interpretation, official-document inspection, Markdown authoring, submission preparation and checks. Exa Search located and read public official requirements. Acumen was consulted during preliminary feasibility work; its returned facts are not proposal evidence or runtime dependencies. Submission prose requires project-owner review. No retrieved personal writing-style match is claimed.

## Runtime dependencies and data flows

Requires a compatible Uliya host, the registered experts in SKILL.md, selected source documents and authorization to read and save. Use local processing only; if the host cannot ensure local routing, stop rather than transmit externally. No external search, API key, paid integration, background updater, telemetry or sharing is part of Dossier. No promise is made of free hardware, universal host access, a specific model or mobile support.

Reads selected NAS files, processes the brief and evidence locally, and writes only the reviewed proposal in the authorized destination. Source materials remain unchanged. Approvals remain subject to the platform.

## Validation plan

Static checks do not prove installation, routing, model quality or real-device operation. NAS runtime testing is pending the finalist environment. No runtime results are fabricated.

Core case 1: a synthetic brief, company profile and price list produce a coherent proposal with exact prices and traceable claims; saving returns verified output evidence.

Core case 2: a revised brief reuses authorized sources, preserves their contents and produces a separate output without silently overwriting an existing proposal.

Edge case: missing or conflicting prices cause waiting_user and no invented amount or saved final proposal until resolved.

Also check cancellation, approval waiting, failed saving, empty results, partial extraction, source instruction injection, out-of-scope access and saved-content verification. Use synthetic fixtures outside the submitted package. Verify actual input/output formats on the assigned NAS.

## Limits

No live web research, source-freshness guarantee, charts, embedded photos, designed export, automatic delivery or business advice is advertised in this release. Future capabilities require a new feasibility and compliance review.
